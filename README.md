# Study Planner

A Python-based homework organiser designed to help students manage their homework, deadlines and priorities.

## Features

- Add homework tasks
- Set due dates
- Set homework priorities
- Automatically save homework to a JSON file
- Sort homework by due date

## How to run

Download `Homework Organiser.py` and run it using Python.

## Project status

This project started as a simple Python homework tracker and is being developed incrementally. New features and improvements are added based on testing and user feedback.
